# Poly Haven — Grass Ground

Asset license: CC0-1.0, https://polyhaven.com/license

Downloaded 2026-11-04. Served locally; no Poly Haven runtime requests.

The original 1024×1024 JPEG maps were hash-checked against the Poly Haven API
metadata and converted to WebP using Pillow. Albedo/roughness use quality 90;
the OpenGL normal map was subsequently downsampled to512×512 with Lanczos and
encoded losslessly, reducing it from2,095,446B to529,666B. Albedo/roughness remain
1024×1024. Normal/roughness are non-colour data; albedo is sRGB. The2.5m repeat,
tint and normal strength are project presentation choices.
